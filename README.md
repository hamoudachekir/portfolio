# Hamouda Chekir — Portfolio

Full-Stack & AI engineer portfolio (ESPRIT TWIN). Featured work: **NextHire** PFE at Talan.

**Live stack:** React 19 · Vite · Tailwind CSS · Framer Motion

## Run locally

```bash
npm install
npm run dev
```

## Content

Edit `src/data/profile.js` for experience, projects, skills, and contact.

## Deploy

Push to GitHub and connect on Netlify (`netlify.toml` already set).

Repo: https://github.com/hamoudachekir/portfolio
